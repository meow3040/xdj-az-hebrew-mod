# Touch FX0.8.0 beta — source build

Touch-controlled STEMS and Drum Roll effects for XDJ-AZ, with adaptive layouts,
per-deck memory, mixer following, transparent backgrounds and customisable pointers.

STEMS Touch FX requires tracks separated using Kyle's AZ-MODS Mod Manager, with
STEMS enabled on the deck. Sampler uses its own samples.

This is a custom source-build beta, not a standalone Community Mod installer.
Matching custom core and audio libraries are mandatory. See BUILD.md and INSTALL.md
for the firmware target, asset extraction and developer-mode requirements.
No proprietary firmware assets or database key bytes are included in this source.
